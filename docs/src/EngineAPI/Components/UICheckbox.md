### UICheckbox

A checkbox with a label. It extends [UIContainer](/EngineAPI/Components/UIContainer), so the label is just a child UI element, and it renders a check box next to it. Click anywhere on it to toggle.

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| checked | checkbox | `false` | Whether the box is checked. |
| accentColor | color | `#ffffff` | The color of the check. |
| labelPosition | select | `right` | `right` or `left`. Where the label sits. |

It inherits the shared [UIElement](/EngineAPI/Components/UIElement) and container props.
